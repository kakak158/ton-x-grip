## TONX Grip Website

The TONX Grip Socks website is under development. This first look includes a
product introduction, a scroll-driven problem section, a grip-sock explainer, a
purchase call to action, and a short FAQ.

### Pages

- `/` — Homepage
- `/about` — About page under construction
- `/contact` — Contact page under construction
- `/privacy` — Privacy page under construction

The About, Contact, and Privacy pages share a placeholder with a link back to
the homepage.

### Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Checks

```bash
npm run lint
npm run build
```
